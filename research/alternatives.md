# Alternatives screened (qualitative early-stage scores)

Weighted criteria: real impact 30%, differentiation 20%, engineering feasibility 20%, reproducibility 15%, world-record potential 10%, community 5%.

Candidates:
- OpenActionProof: adversarial outcome-verifier conformance.
- ReproEval: agent execution replay and reproduction.
- Signed receipt infrastructure.
- Result-normalized AI cost reporting.
- Tool-use prompt-injection boundary assessment.
- Agent framework interoperability.

Decision: prioritize the first candidate for a small falsifiable local MVP. It is not an evidence-backed market leadership ranking. Novelty and advantage must be measured against existing tools before further claims.

Disconfirmation: if standard Inspect AI scorers or existing open-source tools pass the same held-out adversarial suite at comparable implementation cost and latency, a standalone verifier adds insufficient value. Reconsider contribution to existing ecosystems.
