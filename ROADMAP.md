# Roadmap

- M0: Offline three-scenario outcomes + verifiable local JSON receipt + tests (prototype)
- M1: Adversarial conformance fixtures for third-party outcome verifiers, plus typed contracts, HTTP sandbox and idempotency
- M2: Independent observer process and attestations, no shared mutable trust boundary
- M3: Model/framework adapters + OpenTelemetry-compatible correlation
- M4: Benchmark with held-out tasks, baseline and confidence intervals
- M5: External replication, API hardening, releases and community review
- G1: Seek Guinness eligibility and guidelines only if user authorizes application
