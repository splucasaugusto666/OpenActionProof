# Roadmap

- M0: Offline three-scenario outcomes + verifiable local JSON receipt + tests (prototype)
- M1: Adversarial conformance fixtures for third-party outcome verifiers, plus typed contracts, HTTP sandbox and idempotency
- M2: Independent observer process and attestations, no shared mutable trust boundary
- M3: Model/framework adapters + OpenTelemetry-compatible correlation
- M4: Benchmark with held-out tasks, baseline and confidence intervals
- M5: External replication, API hardening, releases and community review
- G1: Seek Guinness eligibility and guidelines only if user authorizes application

## Autonomous economic trust track (experimental)

- E0: Local atomic budget reservation ledger with request identity, immutable terminal transitions and concurrent regression tests. See [economic trust contract](docs/ECONOMIC_TRUST.md).
- E1: Trusted dispatch binding and independent cost reconciliation; unknown outcomes retain holds.
- E2: Mock gateway and policy/approval adapter; interoperable capability discovery.
- E3: Independent held-out concurrency and failure benchmarks; test-environment integrations only.
- E4: Production-readiness review and verified adoption, no real-money capability before explicit authorization and security validation.
